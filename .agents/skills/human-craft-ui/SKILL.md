# Human-Craft UI & Minimalist AI Avoidance

When designing user interfaces, avoid patterns that make a web app look like a generic template or AI boilerplate:

## Core Principles

1. **No Decorative Header Chips (Anti-AI Badge Trope):**
   - ❌ Never place small pill chips (`✦ Next-Gen Feature`, `✦ Sanctum Hub`, `✦ AI Powered`) above section headers or page titles.
   - ✅ Let clean, confident typography and strong semantic hierarchy communicate the section's purpose naturally.

2. **Editorial Typography Hierarchy:**
   - Use bold, prominent headings (`text-3xl` to `text-5xl`, `font-extrabold`).
   - Generous body line heights (`leading-[1.7]` to `leading-[1.9]`).
   - Avoid microscopic font sizes (minimum 13px–14px for metadata/mono).

3. **High Contrast Dark Mode:**
   - In Dark Mode, ensure icons and inactive switches are clearly visible with distinct surface tones and subtle 1px borders, never pitch-black invisible elements.

4. **Intentional Spacing & Breathing Room:**
   - Let content breathe with 48px–96px section gaps rather than boxing everything into tiny repetitive cards.
